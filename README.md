# چاپکرنا ناسنامان (ID Card Printer) — v3

ئەپەکێ HTML یێ تاک: ڕووێ پێشی یێ 4 ناسنامان ل لاپەڕەکێ، و ڕووێ پاشی ل پشتا وێ (هەر پاشەک ل پشتا پێشیا خۆ)، ب مەزناهیا ڕاستەقینە (85.6×54 ملم) ل سەر A4، وەک PDF.

## تایبەتمەندی
- قصکرنا ئۆتۆماتیک یا ناسنامێ ژ وێنەی (ب دەست ژی دشێی ڕێک بێخی)
- ڕیزکرنا وێنەکان ب دەمێ وێنەگرتنێ، جووتکرنا هەر 2 وێنە (پێشی/پاشی)، و دیتنا ڕووێ پێشی ب ڕووخسار/ڕەنگێ پێستێ (دشێی ب دەست ژی ڤەبگۆڕی)
- لاپەڕا مەعایرەکرنا چاپگەری و پاراستنا جهگۆڕینێ
- چاپکرنا ل سەر 2 ڕووان (Flip on long edge / short edge)

## پاراستنا نهێنیێ
- هەمی کار ل ناڤ وێبگەڕێ تە دهێتە کرن؛ **چ وێنە ناهێنە بارکرن**.
- ل ناڤ وێبگەڕێ تەنێ **ڕێکخستن** (مەزناهی/جهگۆڕین) دهێنە پاراستن، **نە وێنە**.
- ئەڤ مستودعە تەنێ کودە. فایلێن `.gitignore` ڕێ نادەن وێنە/PDF بهێنە بارکرن.

## بکارئینان
1. `index.html` ل وێبگەڕێ ڤەکە (یان ژ لینکێ GitHub Pages).
2. وێنەکان زێدە بکە ← پێشدیتن ← دابەزاندنا PDF.
3. ل دەمێ چاپێ: 2 ڕوو، **Flip on long edge**، و **100% / Actual size**.

## petition/ — عەریزا مۆلەتێ

صفحەیەکا ب تنێ بو نڤیسینا عەریزێن مۆلەتێ. هەمی عەریز و کارمەند تنێ ل سەر ئامیرێ تە د وێبگەرێ دا دهێنە پاراستن، ب پاسۆۆردەکێ هاتینە قفلکرن (AES-256). د ڤی مستودەعێ دا چ داتایێن کەسی نینن.

چ داتا ژ ئامیرێ تە ناچیتە دەرڤە. کۆپییا پاراستنێ ب «پاراستن ل Files» ل سەر ئامیرێ خۆ دهێتە پاراستن.

**petition/employee/** — لینکێ کارمەندان: فۆرمەکا فارغ ب بێ پاسۆۆرد و ب بێ ئەرشیڤ. کارمەند عەریزا خۆ دنڤیسیت و چاپ دکەت. QRـا سەر کاغەزێ داتایێن عەریزێ تێدایە، و ب سکانکرنا ڤێ QRـێ ل ئەپێ سەرەکی عەریز دچیتە ئەرشیڤا مدیری. چ داتا ناهێتە ناردن و چ نابێتە پاراستن ل سەر ئامیرێ کارمەندی.
