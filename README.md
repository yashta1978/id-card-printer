# چاپکرنا ناسنامان (ID Card Printer) — v2

ئەپەکێ HTML یێ تاک: ڕووێ پێشی یێ 4 ناسنامان ل لاپەڕەکێ، و ڕووێ پاشی ل پشتا وێ (هەر پاشەک ل پشتا پێشیا خۆ)، ب مەزناهیا ڕاستەقینە (85.6×54 ملم) ل سەر A4، وەک PDF.

## تایبەتمەندی
- قصکرنا ئۆتۆماتیک یا ناسنامێ ژ وێنەی (ب دەست ژی دشێی ڕێک بێخی)
- لاپەڕا مەعایرەکرنا چاپگەری و پاراستنا جهگۆڕینێ
- چاپکرنا ل سەر 2 ڕووان (Flip on long edge / short edge)

## پاراستنا نهێنیێ
- هەمی کار ل ناڤ وێبگەڕێ تە دهێتە کرن؛ **چ وێنە ناهێنە بارکرن**.
- ل ناڤ وێبگەڕێ تەنێ **ڕێکخستن** (مەزناهی/جهگۆڕین) دهێنە پاراستن، **نە وێنە**.
- ئەڤ مستودعە تەنێ کودە. فایلێن `.gitignore` ڕێ نادەن وێنە/PDF بهێنە بارکرن.

## بکارئینان
1. `index.html` ل وێبگەڕێ ڤەکە (یان ژ لینکێ GitHub Pages).
2. وێنەکان زێدە بکە ← پێشدیتن ← دابەزاندنا PDF.
3. ل دەمێ چاپێ: 2 ڕوو، **Flip on long edge**، و **100% / Actual size**.
